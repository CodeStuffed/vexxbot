# Stacker robot build guide

Static site, plain HTML. Opens straight to the 3D build steps.

Upload everything in this folder to the root of the repo (replace the old files, delete the old `build3d/` and `media/` folders), then Settings > Pages > Deploy from a branch > `main` > `/ (root)`.

- `index.html`: 3D build steps (needs a web server such as GitHub Pages)
- `steps/`: picture steps
- `parts.html`: parts, tools, cut list
